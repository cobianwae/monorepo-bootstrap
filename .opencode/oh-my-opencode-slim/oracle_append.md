## Konteks project

Repo ini design system + aplikasi konsumen; UI/UX adalah identitas utama dan batas package satu arah (`tokens -> ui -> apps`, `shared-types` tidak import UI). Nilai usulanmu terhadap gate project (PRD/design/story), aturan konfirmasi di `docs/CONVENTIONS.md` (dependency baru, API publik, token, arah dependency), dan baseline known-issues di `docs/STATUS.md` — jangan rekomendasikan perbaikan di luar scope sebagai syarat.
